Windsurf

One global file: ~/.codeium/windsurf/mcp_config.json. There is no per-project file.

Clients Cursor VS Code Claude Windsurf CLI Browser Settings

Save the file and reload Windsurf. A remote server uses serverUrl. A field named url is ignored.

Local npx

stdio. Windsurf does not document a working directory, so npx is the entry that does not depend on one.

{
  "mcpServers": {
    "code-engine": {
      "command": "npx",
      "args": ["-y", "code-engine-mcp-server@latest"],
      "env": {
        "IBMCLOUD_API_KEY": "your-ibm-cloud-api-key",
        "IBMCLOUD_REGION": "us-south"
      }
    }
  }
}

Hosted server

Streamable HTTP. Replace the host with your app.

{
  "mcpServers": {
    "code-engine": {
      "serverUrl": "https://your-app.namespace.region.codeengine.appdomain.cloud/mcp"
    }
  }
}
