Quit Claude and open it again after you save. The desktop file starts a local process. It does not take a URL on its own.

Local npx

stdio. The IBM Cloud key is read by the server process.

{
  "mcpServers": {
    "code-engine": {
      "command": "npx",
      "args": ["-y", "code-engine-mcp-server@latest"],
      "env": {
        "IBMCLOUD_API_KEY": "your-ibm-cloud-api-key",
        "IBMCLOUD_REGION": "us-south"
      }
    }
  }
}

Hosted server

mcp-remote opens the hosted URL from that local process. The API key is set on the hosted server.

{
  "mcpServers": {
    "code-engine": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://your-app.namespace.region.codeengine.appdomain.cloud/mcp"
      ]
    }
  }
}

When auth mode is writes or all, pass the server key the way mcp-remote documents an Authorization header. Auth mode open needs no extra key. For a local stdio process, set MCP_API_KEY in env.
