CLI

A small client in this repo. It starts the MCP server over stdio and prints each tool result.

Clients Cursor VS Code Claude Windsurf CLI Browser Settings

This command line client lives in the source tree, so run it from a checkout of the source. The editor pages and the browser page need no checkout.

Build once, then open the prompt. npm start runs build/simple-client.js. It reads IBMCLOUD_API_KEY from the repo .env.

npm run build
npm start

The prompt is mcp>. Type help, then a command. exit quits. The same commands work without the prompt:

./run-client.sh projects
npm start detect

Commands

This client calls a short list. Editors see the full catalog of 28 tools.

detect
images
containers
build <dockerfile> <name> <context>
push <image>
test <image> [port]
logs <container_id>
stop <container_id>
projects
help
exit

projects calls ce_list_projects. The container commands call detect_container_runtime, list_local_images, list_local_containers, build_container_image, push_container_image, test_container_locally, get_container_logs, and stop_local_container. Docker or Podman must be on PATH for those.

Where the code is

src/simple-client.ts is the client. run-client.sh loads .env and runs the built file. npm run client runs the TypeScript source with tsx while you are changing it.
