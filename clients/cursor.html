Cursor

Project file .cursor/mcp.json, or ~/.cursor/mcp.json for every project.

Clients Cursor VS Code Claude Windsurf CLI Browser Settings

Save the file. Open Cursor Settings → MCP and turn code-engine on. A green dot means the handshake worked. In Agent chat, ask: list my Code Engine projects.

Local npx

Cursor starts the process. The IBM Cloud key stays in this file, on your machine. Node.js 18 or newer is required.

{
  "mcpServers": {
    "code-engine": {
      "command": "npx",
      "args": ["-y", "code-engine-mcp-server@latest"],
      "env": {
        "IBMCLOUD_API_KEY": "your-ibm-cloud-api-key",
        "IBMCLOUD_REGION": "us-south"
      }
    }
  }
}

Hosted server

Streamable HTTP. Put your app URL in place of the host. The API key is set on that server, not in this file.

{
  "mcpServers": {
    "code-engine": {
      "url": "https://your-app.namespace.region.codeengine.appdomain.cloud/mcp"
    }
  }
}

When a server key is required

Auth mode open accepts tool calls with no extra credential. describe_server stays open in every mode. When the mode is writes or all, add the header on the hosted entry. Over stdio, set MCP_API_KEY or MCP_USERNAME and MCP_PASSWORD.

{
  "mcpServers": {
    "code-engine": {
      "url": "https://your-app.namespace.region.codeengine.appdomain.cloud/mcp",
      "headers": {
        "Authorization": "Bearer your-server-api-key"
      }
    }
  }
}

An older Cursor setup reaches the same host through npx mcp-remote and /sse. The url block above is the current Streamable HTTP entry.
