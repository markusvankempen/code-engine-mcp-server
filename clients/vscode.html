Command Palette → MCP: List Servers → start code-engine. In Copilot Chat, confirm the server is selected in the tools list, then ask to list Code Engine projects.

Local npx

stdio

{
  "servers": {
    "code-engine": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "code-engine-mcp-server@latest"],
      "env": {
        "IBMCLOUD_API_KEY": "your-ibm-cloud-api-key",
        "IBMCLOUD_REGION": "us-south"
      }
    }
  }
}

Hosted server

HTTP. Replace the host with your app.

{
  "servers": {
    "code-engine": {
      "type": "http",
      "url": "https://your-app.namespace.region.codeengine.appdomain.cloud/mcp"
    }
  }
}

When a server key is required

Leave this out while auth mode is open. Add it when the mode is writes or all.

{
  "servers": {
    "code-engine": {
      "type": "http",
      "url": "https://your-app.namespace.region.codeengine.appdomain.cloud/mcp",
      "headers": {
        "Authorization": "Bearer your-server-api-key"
      }
    }
  }
}

A legacy entry uses "type": "sse" and a URL that ends in /sse.
