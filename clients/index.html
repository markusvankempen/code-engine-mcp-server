Open these pages

With the HTTP server running, open /clients/ on that host. The browser page then calls /mcp on the same origin.

MCP_MODE=http PORT=8787 npx -y code-engine-mcp-server

Or serve this folder by itself. A loopback page may call the server. A page hosted elsewhere is refused until CORS_ORIGINS lists that origin.

cd clients
python3 -m http.server 8765

Then open http://127.0.0.1:8765/. Point the browser page at http://127.0.0.1:8787/mcp.
